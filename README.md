# Badri Portfolio

Stylish deployable portfolio website for Badri Narayana Kancharla, built from
the provided resume context with a custom generated hero asset and responsive
CSS motion.

## Prerequisites

- Node.js `>=22.13.0`

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run build
```

The site is based on the Sites Vinext starter and keeps `.openai/hosting.json`
ready for hosting with no D1 or R2 bindings required.
